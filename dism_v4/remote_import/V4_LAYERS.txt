For each token and head, z = delta_proj(x) uses Linear(width, heads) with bias.
Bias initializes to zero; weights use Linear initialization (or the enclosing
language model's existing weight initialization). CUDA operands use FP32:
  soft attenuation: delta = -logsigmoid(z)
  hard attenuation: delta = 0 if z >= 0 else 1e6
The recurrence already subtracts delta. Equivalently its additive log-gate is
logsigmoid(z), hardened to 0 or LOG_ZERO=-1e6. Sign is tested BEFORE logsigmoid.

hard_prob is shared with vocabulary hardening and follows the same annealing
schedule. Gate and vocabulary masks are independent. Default training is soft
(hard_prob=0); default eval is fully hard (hard_prob=1). Explicit probabilities
and bool delta_hard [B,H,N] masks allow controlled validation. hard_seed gives
reproducible, layer-salted, independent gate masks. Hard rows do not train the
gate projection: only soft rows provide its gradient (no straight-through).
An explicit gate_delta bypass is available for kernel/reference comparisons.

The new hybrid retains the original separate SWA Q/K, shared V, and shared
output norm/gate/projection. Fixed, packed, unpadding, fullgraph compilation,
and cached Torch inference inherit the existing v4-capable paths.

HF model: DismConfig(attention_type='dism_v4' or 'hybrid_v4'). Config and gate
parameters serialize normally; defaults 'dism'/'hybrid' remain unchanged.
nanochat: architecture='dism_v4_hybrid', architecture_version=1, otherwise the
same DismConfig fields. Gate sampling reads the existing GPU hard_probability
buffer: no CPU scalar extraction and no per-step recompilation. Existing
rng_counter checkpoint state reproduces both independent streams. Evaluation
hardens both branches fully. No training was started or changed for this task.
